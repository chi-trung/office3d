# Văn Phòng 3D — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dựng web tĩnh (Vite + React + TypeScript + Three.js thuần) mô phỏng văn phòng 3D isometric với 7 nhân viên, tương tác xoay/zoom/bấm chọn, Day/Night và toggle 2D/3D.

**Architecture:** React DOM overlay đọc/ghi zustand store. Lớp 3D là class `OfficeScene` giữ chính `THREE.WebGLRenderer`, tự chạy animation loop, không phụ thuộc React render cycle. Logic thuần (grid, thống kê, zoom %, validate form, localStorage) nằm riêng trong `src/lib/` để unit test không cần DOM hay WebGL.

**Tech Stack:** Vite, React 18, TypeScript (strict), Three.js (plain), zustand, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-10-office3d-design.md`

## Global Constraints

- Chỉ dùng `three`, `react`, `react-dom`, `zustand` + dev deps (`vite`, `@vitejs/plugin-react`, `typescript`, `vitest`). **Không** React Three Fiber, drei, GSAP, Framer Motion, animation library hay model loader.
- TypeScript strict: không `any`, không `@ts-ignore`.
